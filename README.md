# Sudeste Asiático · Planificador Interactivo de Viaje

Mapa interactivo y comparador de rutas, vuelos, presupuestos reales y hoteles para planificar un viaje al Sudeste Asiático desde Argentina (EZE).

## Contenido
- **Rutas en mapa interactivo (Leaflet):** Comparativa de 3 viajes reales de referencia + constructor personal (**Mi Viaje**).
- **Simulador de pasaje ida y vuelta / multidestino:** Recomendación de aeropuertos hub según mes (monzón) y días disponibles.
- **Presupuesto real y buscador de hoteles:** Gastos reales discriminados por ciudad + catálogo filtrable de +115 hoteles.
- **Guía 101:** Matriz climática mes a mes, visas para pasaporte argentino y vacuna de fiebre amarilla.

## Uso local
```bash
python3 -m http.server 8765
```
Abrir `http://localhost:8765/`.
